# Как опубликовать «Сказочную мастерскую» на GitHub

## 1. Создайте репозиторий

1. Войдите в аккаунт на [github.com](https://github.com).
2. Нажмите **New repository**.
3. Название, например `skazochnaya-masterskaya`.
4. Выберите **Public**, если хотите, чтобы сайт был доступен всем, или **Private**, если нужен частный репозиторий. Доступность Pages для приватных репозиториев зависит от тарифных условий GitHub.
5. Нажмите **Create repository**.

## 2. Загрузите файлы из папки

Откройте только что созданный репозиторий, выберите **Add file → Upload files** и перетащите **содержимое** папки `skazochnaya-masterskaya-github` (включая `index.html`) в корень репозитория. На некоторых системах веб-загрузка скрытых папок, например `.github`, может работать иначе — это необязательные файлы, сайт без них запустится.

**Не кладите всю папку внутрь другой папки в репозитории:** `index.html` должен лежать в корне для простой настройки GitHub Pages.

Нажмите **Commit changes**. Если интерфейс GitHub не переносит скрытые файлы, можно загрузить их через GitHub Desktop или `git`.

## 3. Включите сайт GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/(root)`.
4. Сохраните настройки (**Save**).
5. GitHub покажет адрес опубликованного сайта, обычно в формате `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Изменения в `index.html` на ветке `main` будут публиковаться при последующих обновлениях репозитория.

## 4. Проверьте сайт

- Кнопки выбора классов и предметов переключаются.
- Для любого месяца показываются четыре тематические недели.
- Выбор темы меняет текст промпта.
- Кнопка скачивания TXT работает.
- Копирование через кнопку должно работать на HTTPS-сайте; локально (при открытии `file://`) для некоторых браузеров возможны ограничения буфера обмена, поэтому предусмотрено выделение/копирование вручную.

## 5. Как обновлять темы

При наличии Python 3 в корне проекта:

```bash
python build_data.py
python build_html.py
```

После обновления загрузите новые `curriculum.json`, `curriculum.csv` и `index.html` в репозиторий. **Изменения только в CSV не обновляют сайт**, поскольку данные встроены в HTML на этапе сборки.

## Необязательный вариант через терминал

```bash
git init
git add .
git commit -m "Initial commit: fairy-tale worksheet prompt builder"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/skazochnaya-masterskaya.git
git push -u origin main
```

Замените `ВАШ-ЛОГИН` своим именем пользователя. Репозиторий должен быть создан заранее; для push потребуется авторизация GitHub.

**Учитывайте:** сайт публично доступен на GitHub Pages только при соответствующих настройках репозитория и тарифа. Публикация здесь не равнозначна публикации с открытой лицензией.
